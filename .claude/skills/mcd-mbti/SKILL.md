# mcd-mbti · 麦门人格鉴定器

把 MBTI 式趣味测试搬进麦当劳语境：不是查你的历史数据，而是**让用户答题 → 鉴定人格 → 用真实菜单/活动/券生成「本命套餐处方」人格卡**，形成「测完就想买、测完就想晒」的闭环。

## 触发示例

- 「测测我是什么麦门人格 / 麦当劳人格测试 / 我是哪一型」
- 「生成我的麦门人格卡」「M-BTI 测一下」
- `/mcd-mbti`

## 四个维度（麦当劳语境包装 MBTI 四轴）

| 轴 | 含义 | 一极 | 另一极 |
|----|------|------|--------|
| E/I | 社交能量 | 堂食社牛 E | 外送独享 I |
| S/N | 选择风格 | 固定本命 S | 每次尝鲜 N |
| T/F | 决策依据 | 性价比理性 T | 心情/联名感性 F |
| J/P | 行动节奏 | 提前规划领券 J | 到店随缘 P |

组合成 16 型，如「🍟 薯条守护神 ENFP」「🥤 续杯战略家 INTJ」「🍔 巨无霸原教旨主义者 ISTJ」。完整定义见 `src/personas.js`。

## 执行流程

### Step 1 — 出题
依次向用户呈现 `src/questions.js` 中的 8 道题（每维 2 题），每题二选一。
- 交互式：逐题提问，收集用户选择。
- 快速模式：用户也可一句话描述自己（如「我爱堂食、每次都点新品、看心情、从不提前领券」），由你映射到各维选项。
记录答案为 `{ q1:'E', q2:'I', ... }`，值取所选选项的 `value` 字母。

### Step 2 — 计分得人格码
调用 `src/engine.js` 的 `score(answers)` 得到四字母人格码（平局时取维度首字母，保证结果可复现）。再 `resolvePersona(code)` 取人格定义。

### Step 3 — 用 MCP 生成「本命套餐处方」
这是本技能的灵魂：把人格落到**真实可下单的麦当劳餐品**上。
1. `now-time-info` 获取当前时间（用于活动匹配）。
2. `query-nearby-stores`（若用户给了位置）或让用户确认门店，得到可售菜单上下文。
3. `query-meals` 获取当前门店在售餐品。
4. 用人格的 `cravePrefs` 关键词（见 personas.js）从菜单里匹配出本命套餐 Top3（`engine.prescribeCombo`）。
5. 可对首选餐品调 `query-meal-detail` 补充套餐组成（可选）。

### Step 4 — 匹配活动与可领券（增强传播 + 导流）
6. `campaign-calendar` 获取当月活动，挑 2-3 个与人格调性相符的（如尝鲜型配「新品周」，省钱型配「第二份半价」）。
7. `available-coupons` 获取当前可领券，列出 2-3 张「顺手领」的券。
> 以上均为只读查询，**不自动领券、不下单**。是否领券/下单由用户自行决定。

### Step 5 — 组装并渲染人格卡
1. 用 `engine.buildCard({ answers, meals, campaigns, coupons })` 组装人格卡模型。
2. 渲染海报：
   ```bash
   node src/render.js --answers <answers.json> --mcp <mcp.json> --out mcd-mbti-card.png
   ```
   无 puppeteer 时自动降级为可截图 HTML。
3. 输出：人格卡（1080×1350 竖版）+ 文字版鉴定结果（含人格称号、金句、本命套餐、最搭人格），并引导用户「把你的 M-BTI 发出来，看看朋友是哪一型」。

## 为什么这个 Skill 有价值（给评审看）

- **娱乐 → 转化闭环**：MBTI 式测试天然病毒传播；而「本命套餐处方 + 可领券」把娱乐流量真实导向麦当劳菜单与优惠，对品牌有实际拉新/复购价值。
- **官方不可替代**：性格测试是 UGC 玩法，不与官方年终活动撞车，可随时玩、反复分享。
- **MCP 用得真**：`query-meals` / `query-meal-detail` / `campaign-calendar` / `available-coupons` / `now-time-info` 真实串联，人格结果直接作用于真实菜单。

## 安全与合规

- 全程只读；绝不调用 `auto-bind-coupons`、`create-order`、`mall-create-order`、`draw-lottery` 等写/消耗类 Tool。
- 不收集、不存储用户个人数据；测试答案仅用于本次人格卡生成。
- 控制 Tool 调用总数（目标 ≤8 次/次），避免触发 600 次/分钟限流。
